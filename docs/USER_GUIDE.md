## Getting Started

### First Time Access
1. Open the Bible Reader in your web browser
2. The app will load the initial data (takes ~3 seconds on first visit)
3. Future visits will be nearly instant thanks to offline caching

- **Complete New Testament**: All 27 books from Matthew to Revelation

## Discovering Related Passages

### How It Works
The Bible Reader uses artificial intelligence to find verses that are semantically similar - meaning they share similar themes, concepts, or ideas, even if they don't use the exact same words.

### Viewing Related Passages
1. Select any verse to view its commentary
2. Scroll down in the commentary panel
3. See **"Related Passages"** section with AI-powered suggestions
4. Each related passage shows:
   - **Verse Reference**: Book, chapter, and verse
   - **Similarity Score**: How closely related (0-100%)
   - **Connection Type**: What kind of relationship exists
   - **Full Verse Text**: Complete text of the related verse

### Connection Types

#### 🔵 Thematic Connection
Similar theological themes and concepts, even if using different words.

**Example:** "Love your neighbor" passages across different books

#### 🟢 Cross-Reference
Traditional biblical cross-references that scholars have identified over centuries.

#### 🟡 Parallel Passage
The same event or teaching recorded in different Gospel accounts.

**Example:** The feeding of the 5,000 in Matthew, Mark, Luke, and John

#### 🟣 Quotation
Direct quotes from the Old Testament appearing in the New Testament.

#### 🟠 Allusion
Indirect references or echoes of other biblical passages.

### Navigating to Related Passages
1. **Click any related passage card**
2. The app will automatically navigate to that book and chapter
3. The selected verse will be highlighted
4. Commentary and related passages will load for the new verse

## Troubleshooting

### Common Issues

#### "Loading" Appears Indefinitely
**Solution:**
1. Check your internet connection
2. Refresh the page (Ctrl+R or Cmd+R)
3. Clear browser cache and reload

#### Commentary Not Showing
**Possible Causes:**
- Verse may not have commentary available (only 4,739 of 7,217 verses have commentary)
- Check if the commentary panel is closed - click any verse to open

**Solution:**
- Try selecting a different verse
- Look for verses in Matthew or Mark (highest commentary coverage)

#### Related Passages Not Appearing
**Solution:**
1. Ensure you've selected a verse
2. Wait for the "Discovering connections..." message to complete
3. Some verses may have fewer than 5 related passages

#### App Slow to Load
**Possible Causes:**
- First visit loads ~95MB of data
- Slow internet connection

**Solutions:**
- Wait for initial load to complete (only happens once)
- Subsequent visits will be instant (cached locally)
- Close other browser tabs to free up memory

#### Verse Text Missing
**Issue:** Rare edge case with single-chapter books

**Solution:**
- This has been fixed in the latest version
- If you see this, refresh the page

### Browser Compatibility

#### Recommended Browsers
- **Chrome/Edge**: 90+
- **Firefox**: 88+
- **Safari**: 14+

#### Not Supported
- Internet Explorer (use Edge instead)
- Very old mobile browsers

### Performance Optimization

#### If the App Feels Slow
1. **Close other tabs**: Free up memory
2. **Clear old cache**: Settings → Clear browsing data
3. **Update browser**: Use the latest version
4. **Disable extensions**: Some extensions can slow down web apps

## Tips for Bible Study

### Effective Use of Features

#### Thematic Study
1. Select a key verse on your topic
2. Review related passages to find similar themes
3. Use commentary to understand deeper meaning
4. Follow connections to build comprehensive understanding

#### Comparative Study
1. Read a Gospel passage
2. Check related passages for parallel accounts
3. Compare how different authors describe the same event
4. Use commentary to understand differences

#### Word Study
1. Find a key verse with important terminology
2. Use related passages to see how concept appears elsewhere
3. Read commentary for theological context
4. Track thematic connections across books

### Study Workflows

#### Daily Reading
1. Select your daily reading chapter
2. Read through without selecting verses
3. Go back and select verses that stand out
4. Study commentary and related passages for depth

#### Topic Research
1. Start with a verse you know on the topic
2. Follow related passages to find more verses
3. Build a collection of relevant passages
4. Study commentary for each for deeper understanding

#### Sermon Preparation
1. Select your main text
2. Review all related passages
3. Study commentary for context and application
4. Find supporting verses from related passages

## About the Data

### Bible Translation
- **Version**: American Standard Version (ASV)
- **Year**: 1901
- **Status**: Public domain
- **Scope**: Complete New Testament

### Commentary Source
- **Author**: John Gill (1697-1771)
- **Work**: Exposition of the Entire Bible
- **Style**: Detailed theological and historical exposition
- **Status**: Public domain

### AI Technology
- **Model**: sentence-transformers/all-MiniLM-L6-v2
- **Method**: Semantic similarity using 384-dimensional embeddings
- **Accuracy**: 7,217 verses embedded with 36,096 connections computed
- **Privacy**: All AI processing done offline, no data sent to servers
